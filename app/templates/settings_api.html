Endpoint Tulis
MetodeJalurKeterangan
PATCH /api/siswa/{nisn} Perbarui sebagian kolom siswa. Dipakai bot Dapodik setelah validasi.
POST /api/impor Unggah berkas Excel/CSV dan impor otomatis. Parameter mode, dry_run.
Contoh
# 1. Ambil daftar siswa kelas 9D curl -H "X-API-Key: {{ api_key }}" \ "{{ base_url }}/api/siswa?rombel=9D&per_page=5" # 2. Perbaiki NIK seorang siswa (bot Dapodik) curl -X PATCH -H "X-API-Key: {{ api_key }}" \ -H "Content-Type: application/json" \ -d '{"nik":"3671101605170001","_actor":"bot-dapodik"}' \ "{{ base_url }}/api/siswa/0113374384" # 3. Uji coba impor berkas tanpa menyimpan curl -X POST -H "X-API-Key: {{ api_key }}" \ -F "berkas=@daftar_pd.xlsx" \ "{{ base_url }}/api/impor?mode=upsert&dry_run=true"
Setiap perubahan yang dikirim melalui API otomatis tercatat pada tabel data_changes beserta nilai lama dan baru, sehingga sinkronisasi ke Dapodik bisa diaudit dan dibatalkan bila perlu.

Rencana Bot Dapodik

  1. Baca — bot mengambil data aplikasi lewat GET /api/siswa dan data Dapodik dari sumbernya.
  2. Bandingkan — cocokkan berdasarkan NISN, tandai kolom yang berbeda.
  3. Pelajari aturan — tentukan mana yang benar menurut aturan Dapodik (mis. format NIK 16 digit).
  4. Kirim perbaikan — PATCH /api/siswa/{nisn} dengan mode uji coba terlebih dahulu.
  5. Audit — tinjau /api/perubahan dan halaman Kualitas Data.
Tahap 1 sudah tersedia: antrean pekerjaan, API, dan jejak perubahan. Tahap 2 (bot penuh) akan ditambahkan setelah alur manual disepakati sekolah.
